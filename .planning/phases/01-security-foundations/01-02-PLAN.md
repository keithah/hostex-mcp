<task type="auto">
  <name>Task 1: Create logger and error handler modules</name>
  <files>src/lib/logger.ts, src/lib/error-handler.ts, package.json</files>
  <action>
    1. Install Pino: `npm install pino@^9.0.0`

    2. Create `src/lib/logger.ts`:
       - Import pino
       - Create and export a logger instance configured to write to stderr (file descriptor 2)
       - Use `pino.destination(2)` for the direct stderr approach (NOT the transport approach, which spawns a worker thread)
       - Set level from `process.env.LOG_LEVEL || 'info'`
       - Use `pino.stdTimeFunctions.isoTime` for timestamps
       - Set base metadata: `{ serverName: 'hostex-mcp' }`
       - Export the logger as a named export

    3. Create `src/lib/error-handler.ts`:
       - Import the logger from `./logger.js`
       - Create and export a `withErrorHandling` function that:
         a. Takes `toolName: string` and an async `handler` function
         b. Returns an async function that wraps the handler in try/catch
         c. On entry: logs `{ tool, requestId }` at info level with message "Tool invoked"
         d. On success: logs `{ tool, requestId, duration }` at info level with message "Tool completed"
         e. On success: returns `{ content: [{ type: "text", text: JSON.stringify(result, null, 2) }], isError: false }`
         f. On error: logs `{ tool, requestId, duration, error, stack }` at error level with message "Tool failed"
         g. On error: returns `{ content: [{ type: "text", text: errorMessage }], isError: true }` with actionable error message
         h. Generate requestId as `Math.random().toString(36).substring(2, 9)`
       - The handler function signature should accept the tool args object
       - Do NOT re-throw errors -- always return isError response

    Follow the patterns from 01-RESEARCH.md exactly. Use `.js` extensions in all import paths (Node16 module resolution requires this).
  </action>
  <verify>
    Run `npx tsc --noEmit` -- both new files should compile without errors.
    Verify src/lib/logger.ts exports `logger`.
    Verify src/lib/error-handler.ts exports `withErrorHandling`.
    Verify no `console.log` appears in either file.
  </verify>
  <done>Logger writes to stderr only. Error handler catches all errors and returns isError responses. Both modules compile.</done>
</task>
